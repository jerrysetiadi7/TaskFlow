MVP:

Register, login, logout
Buat dan kelola Project
Undang member ke project
Buat dan kelola Task dengan status todo, in_progress, done
Assign task ke member
Komentar di task
Kanban board (kolom per status)



ID	User Story
US-1	Sebagai pengunjung, saya ingin mendaftar akun agar bisa memakai aplikasi
US-2	Sebagai user, saya ingin login dan logout dengan aman
US-3	Sebagai user, saya ingin membuat project agar pekerjaan saya terorganisir
US-4	Sebagai owner project, saya ingin menambah/menghapus member
US-5	Sebagai member, saya ingin membuat task di project saya
US-6	Sebagai member, saya ingin mengubah status task agar progres terlihat
US-7	Sebagai member, saya ingin meng-assign task ke rekan tim
US-8	Sebagai member, saya ingin berkomentar di task untuk berdiskusi
US-9	Sebagai user, saya hanya boleh melihat project yang saya ikuti
